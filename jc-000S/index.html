In the previous section, we saw that the subobject classifier gives us the following data:

  • a universal subobject 𝑡:𝑇↪︎Ω (in fact, 𝑡=𝜒id𝑇:𝑇↪︎Ω);
  • for every subobject 𝑢∈Sub(𝐴), a unique morphism 𝜒𝑢:𝐴→Ω such that 𝑢∼𝜒𝑢−1(𝑡).

In this section, we want to see how the subobject classifier internalizes some special subobjects as morphisms in the underlying category. Externally, we have the following concepts:

  • the equality of morphisms 𝑓=𝑔,
  • the membership 𝑥∈𝑢 of a generalized element in a subobject,
  • the logical “and”, or the intersection subobject 𝑢∩𝑣.
    We claim that we can convert each of these concepts into a morphism 𝑝:𝐴→Ω, and that we have a collection of specified morphisms true𝐴:𝐴→Ω, one for each 𝐴, such that 𝑝=true𝐴 is equivalent to 𝑓=𝑔, to 𝑥∈𝑢, or to 𝑞1=true𝐴∧𝑞2=true𝐴, respectively.

First, we focus on finding out what true is.

Recall the greatest subobject id𝐴:𝐴↪︎𝐴∈Sub(𝐴). We have seen that this construction is so uniform that the assignment

{∗}→Sub{∗}→Sub(𝐴)∗↦id𝐴

forms a natural transformation. Now, using the concept of representable functors: the constant singleton functor {∗} is represented by the terminal object 1, and the subobject functor Sub is represented by the subobject classifier Ω, so we have

hom𝒞︀(−,1)≅{∗}→Sub≅hom𝒞︀(−,Ω)

It sends !𝐴↦∗↦id𝐴↦𝜒id𝐴, and naturality says 𝜒id𝐵=𝜒id𝐴𝑓 for every morphism 𝑓:𝐵→𝐴. By the Yoneda lemma, computing id1↦∗↦id1↦𝜒id1, we get a universal element 𝜒id1:1→Ω such that 𝜒id𝐴=𝜒id1!𝐴 for every object 𝐴.

Both 𝑡 and 𝜒id1∈Sub(Ω) have the property that for every 𝑢∈Sub(𝐴) and every generalized element 𝑥:Γ→𝐴 of 𝐴, we have

𝑥∈𝑢⇔𝜒𝑢𝑥∈𝑡𝑥∈𝑢⇔𝜒𝑢𝑥∈𝜒id1

Both act like “true”! Indeed, taking 𝑢≔𝑡 in the second equation, we get 𝑥∈𝑡⇔𝜒𝑡𝑥∈𝜒id1; but 𝜒𝑡=idΩ by construction, so 𝑡∼𝜒id1∈Sub(Ω): they are indeed the same subobject!

Proof of equation 1: by the property of 𝑡, we have 𝑢∼𝜒𝑢−1(𝑡). Expanding the definitions of ∼ and of preimages, we are done.
Proof of equation 2: first, we have 𝑥∈𝑢⇔𝑥−1(𝑢)∼idΓ, since

𝑥∈𝑢⇔𝑥idΓ∈𝑢⇔idΓ∈𝑥−1(𝑢)⇔idΓ≤𝑥−1(𝑢)⇔idΓ∼𝑥−1(𝑢)

where we used that idΓ≤𝑥−1(𝑢) iff idΓ factors through 𝑥−1(𝑢), and that idΓ is the greatest subobject.
Next, we show 𝑥−1(𝑢)∼idΓ⇔𝜒𝑢𝑥∈𝜒id1. If 𝑥−1(𝑢)∼idΓ, applying 𝜒 to both sides, we get

𝜒𝑥−1(𝑢)=𝜒idΓ‖‖𝜒𝑢𝑥𝜒id1!Γ

where the two vertical equalities use the naturality of 𝑢↦𝜒𝑢 and of !𝐴↦𝜒id𝐴. Therefore, 𝜒𝑢𝑥∈𝜒id1.
Conversely, if 𝜒𝑢𝑥∈𝜒id1, say 𝜒𝑢𝑥=𝜒id1𝑦 for some 𝑦:Γ→1, then again by naturality, 𝜒𝑥−1(𝑢)=𝜒𝑢𝑥=𝜒id1𝑦=𝜒idΓ; therefore 𝑥−1(𝑢)∼idΓ.

We should give the universal subobject a new name: true:1↪︎Ω, true≔𝜒id1; then true∼𝑡∈Sub(Ω). It can be understood as a global element of Ω, so it also corresponds to a collection of morphisms true𝐴:𝐴→Ω (in fact, true𝐴=𝜒id𝐴 and true1=true) which is invariant under context substitution: trueΓ𝜎=trueΔ for every 𝜎:Δ→Γ, and so

true𝐴=true!𝐴

for every object 𝐴.

Finally, rewriting the results above, we have

𝑥∈𝑢⇔𝜒𝑢𝑥=true!Γ

for every subobject 𝑢∈Sub(𝐴) and generalized element 𝑥 of 𝐴. Equivalently, the following

    Generalized elements [jc-0004]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a category. In general, for an object 𝐴 in 𝒞︀, we can’t talk about an element of 𝐴. But from the categorical semantics of type theory, or through the lens of the Yoneda lemma, it seems to be a great idea to consider the generalized elements of 𝐴.

    Definition generalized element [jc-0005]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a category and 𝐴 an object of 𝒞︀. A generalized element of 𝐴 is a morphism into 𝐴

    𝑥:Γ→𝐴

    where Γ, the source of 𝑥, is called the context of 𝑥. In the case where 𝒞︀ has a terminal object 1 and the context of 𝑥 is 1, 𝑥 is called a global element of 𝐴.

    The notation of generalized elements makes reasoning about objects very much like reasoning about “sets”. The Yoneda embedding y:𝒞︀→Psh(𝒞︀),𝐴↦hom𝒞︀(−,𝐴) can be viewed as converting an object into its generalized elements, sorted by context (where Psh(𝒞︀)≔Set𝒞︀op is the presheaf category of 𝒞︀, and we should assume 𝒞︀ is locally small so that hom𝒞︀(−,𝐴) takes values in sets). The following exercise gives more intuition about the notation of generalized elements:

    Exercise [jc-0006]

    The name “global element” comes from the following understanding: if we have a global element 𝑐:1→𝐴, we can form the generalized element 𝑐!Γ:Γ→𝐴 for each object Γ, where !Γ:Γ→1 denotes the unique map into the terminal object. Conversely, if we have a collection of generalized elements {𝑐Γ:Γ→𝐴}Γ∈𝒞︀ invariant under context substitution, i.e. 𝑐Γ𝜎=𝑐Δ for every morphism 𝜎:Δ→Γ, then taking 𝑐1:1→𝐴, we have 𝑐1!Γ=𝑐Γ for each object Γ.

    Subobjects [jc-0007]

    • November 3, 2026
    • Justin

    To generalize subsets, we should look at monomorphisms 𝑖:𝑈↪︎𝐴. In the notation of generalized elements, the condition for 𝑖:𝑈↪︎𝐴 to be a monomorphism is: for all generalized elements 𝑥,𝑦 of 𝑈 with the same context, if 𝑖𝑥=𝑖𝑦 then 𝑥=𝑦 (notice that 𝑖𝑥 and 𝑖𝑦 are generalized elements of 𝐴). So postcomposition with 𝑖 can be seen as an inclusion of the generalized elements of 𝑈 into those of 𝐴.

    We can recover the notions of an element lying in a subset, of the inclusion relation between two subsets, and of when two subsets are considered equal.

    Now that we have established the subobject functor, before we step into the subobject classifier, I want to change perspective and look at the greatest subobject id𝐴:𝐴↪︎𝐴 again.

    The construction of id𝐴:𝐴↪︎𝐴 does not seem to depend on the object 𝐴: we can do this “uniform” construction for every object. And maybe there is only one “essential” subobject.

    This construction is “uniform” in the sense that we have id𝐴∈Sub(𝐴) for each object 𝐴, and the functoriality of Sub preserves id𝐴; namely, for any 𝑓:𝐴→𝐵, we have 𝑓−1(id𝐵)∼id𝐴.

Let {∗}:𝒞︀op→Set be the contravariant constant functor sending every object to the singleton set {∗} and every morphism to the identity id{∗} on the singleton set. We can state the uniformity of picking the subobject id𝐴 for each object 𝐴 as follows: we have a natural transformation defined by

    𝜂:{∗}→Sub𝜂𝐴:{∗}→Sub(𝐴)𝜂𝐴:∗↦id𝐴

    Naturality says that for any 𝑓:𝐴→𝐵, the following diagram commutes:

    so id𝐴∼𝑓−1(id𝐵)!

    Naturality describes the “uniform” part, and the Yoneda lemma helps us find the “essential” core. Recall the definition of the terminal object 1: for any object 𝐴, there is one and only one arrow !𝐴:𝐴→1 from 𝐴 into 1; in other words, hom𝒞︀(𝐴,1) is a singleton set, so we have a bijection of sets

    {∗}≅hom𝒞︀(𝐴,1),∗↦!𝐴

    Moreover, this bijection is natural in 𝐴 (the assignment of !𝐴 to each object 𝐴 is also uniform); that is, the following defines a natural transformation (in fact, a natural isomorphism, since every component is a bijection):

    𝜉:{∗}≅hom𝒞︀(−,1)𝜉𝐴:{∗}≅hom𝒞︀(𝐴,1)𝜉𝐴:∗↦!𝐴

    Using the fact that the functoriality of hom𝒞︀(−,1) is given by precomposition (∘𝑓):hom𝒞︀(𝐵,1)→hom𝒞︀(𝐴,1), one can check that the naturality of 𝜉 says !𝐴=!𝐵𝑓 for every 𝑓:𝐴→𝐵. Composing them, we get a natural transformation

    𝜃≔𝜂𝜉−1:hom𝒞︀(−,1)≅𝜉−1{∗}→𝜂Sub

    whose component at 𝐴 is hom𝒞︀(𝐴,1)→Sub(𝐴),!𝐴↦id𝐴.

    Think about how to make a uniform mapping that sends a morphism 𝑓:𝐴→1 to a subobject 𝑢𝑓∈Sub(𝐴) of 𝐴, where the mapping has to work for every object 𝐴. If we have a subobject 𝑣∈Sub(1) of 1, we can use the functoriality of Sub to get 𝑓−1(𝑣)∈Sub(𝐴). It turns out that this is the only way to make such a uniform mapping! The trick is that we can use id1:1→1 to detect such a uniform mapping!

    Consider the component of 𝜃:hom𝒞︀(−,1)→Sub at 1, with input id1:

    𝜃1:hom𝒞︀(1,1)→Sub(1)𝜃1:id1=!1↦id1

    (On the left-hand side, id1:1→1 is a morphism; on the right-hand side, id1:1↪︎1 is a subobject in Sub(1).)

    so id𝐴∼!𝐴−1(id1)∈Sub(𝐴). Every greatest subobject id𝐴∈Sub(𝐴) is a shadow of the “essential” core id1∈Sub(1), in the sense that id𝐴 is the preimage of id1 under !𝐴 for every object 𝐴.

    Definition [jc-000Q]

    The subobject classifier Ω is the representing object of the subobject functor Sub. Explicitly, Ω is an object of 𝒞︀ together with a natural isomorphism

    𝜒:Sub≅hom𝒞︀(−,Ω)

    From the discussion above, we expect the naturality of 𝜒 to give us a uniform way to convert a subobject of 𝐴 into a morphism into Ω. We encourage the reader to play around with the naturality of 𝜒 and see what the examples in the previous sections correspond to; you may be able to guess all the constructions we will do in the sections below.

    Let’s unpack the definition of the subobject classifier:

    𝜒:Sub≅hom𝒞︀(−,Ω)𝜒𝐴:Sub(𝐴)≅hom𝒞︀(𝐴,Ω)𝜒𝐴:𝑢↦𝜒𝐴(𝑢)≕𝜒𝑢

    First, 𝜒 is a natural transformation; it has a component 𝜒𝐴:Sub(𝐴)→hom𝒞︀(𝐴,Ω) for each object 𝐴. Let’s denote the image of a subobject 𝑢∈Sub(𝐴) under 𝜒𝐴 by 𝜒𝑢≔𝜒𝐴(𝑢).     The naturality of 𝜒 gives (can you guess what it is just by recalling the functoriality of Sub and hom𝒞︀(−,Ω), without drawing the naturality square?), for any morphism 𝑓:𝐴→𝐵, that

    commutes, that is, 𝜒𝑓−1(𝑢)=𝜒𝑢𝑓 for every subobject 𝑢∈Sub(𝐵). (Compare this with the set-theoretic indicator function of a subset!)
