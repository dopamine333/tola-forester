Theorem. Yoneda lemma [jc-000L]

  • November 3, 2026
  • Justin

Let 𝒞︀ be a locally small category, 𝐹:𝒞︀op→Set a contravariant set-valued functor, and 𝑋 an object of 𝒞︀. Then we have a bijection

homPsh(𝒞︀)(hom𝒞︀(−,𝑋),𝐹)≅𝐹(𝑋)

which sends a natural transformation 𝜂∈homPsh(𝒞︀)(hom𝒞︀(−,𝑋),𝐹), i.e. 𝜂:hom𝒞︀(−,𝑋)→𝐹, to the element 𝜂𝑋(id𝑋)∈𝐹(𝑋) (the essential core!). Here Psh(𝒞︀)≔Set𝒞︀op denotes the presheaf category, whose objects are functors and whose morphisms are natural transformations. There is also a version for covariant set-valued functors 𝐺:𝒞︀→Set.

    Now that we have established the subobject functor, before we step into the subobject classifier, I want to change perspective and look at the greatest subobject id𝐴:𝐴↪︎𝐴 again.

    The construction of id𝐴:𝐴↪︎𝐴 does not seem to depend on the object 𝐴: we can do this “uniform” construction for every object. And maybe there is only one “essential” subobject.

    This construction is “uniform” in the sense that we have id𝐴∈Sub(𝐴) for each object 𝐴, and the functoriality of Sub preserves id𝐴; namely, for any 𝑓:𝐴→𝐵, we have 𝑓−1(id𝐵)∼id𝐴.

    Indeed, for every generalized element 𝑥 of 𝐴, we have 𝑥=id𝐴𝑥 and 𝑓𝑥=id𝐵𝑓𝑥, so both 𝑥∈id𝐴 and 𝑓𝑥∈id𝐵 (i.e. 𝑥∈𝑓−1(id𝐵)) hold; hence id𝐴∼𝑓−1(id𝐵).

    This is exactly the idea of a natural transformation!     Naturality describes the “uniform” part, and the Yoneda lemma helps us find the “essential” core. Recall the definition of the terminal object 1: for any object 𝐴, there is one and only one arrow !𝐴:𝐴→1 from 𝐴 into 1; in other words, hom𝒞︀(𝐴,1) is a singleton set, so we have a bijection of sets

    {∗}≅hom𝒞︀(𝐴,1),∗↦!𝐴

    Moreover, this bijection is natural in 𝐴 (the assignment of !𝐴 to each object 𝐴 is also uniform); that is, the following defines a natural transformation (in fact, a natural isomorphism, since every component is a bijection):

    𝜉:{∗}≅hom𝒞︀(−,1)𝜉𝐴:{∗}≅hom𝒞︀(𝐴,1)𝜉𝐴:∗↦!𝐴

    Using the fact that the functoriality of hom𝒞︀(−,1) is given by precomposition (∘𝑓):hom𝒞︀(𝐵,1)→hom𝒞︀(𝐴,1), one can check that the naturality of 𝜉 says !𝐴=!𝐵𝑓 for every 𝑓:𝐴→𝐵. Composing them, we get a natural transformation

    𝜃≔𝜂𝜉−1:hom𝒞︀(−,1)≅𝜉−1{∗}→𝜂Sub

    whose component at 𝐴 is hom𝒞︀(𝐴,1)→Sub(𝐴),!𝐴↦id𝐴.

    Think about how to make a uniform mapping that sends a morphism 𝑓:𝐴→1 to a subobject 𝑢𝑓∈Sub(𝐴) of 𝐴, where the mapping has to work for every object 𝐴. The trick is that we can use id1:1→1 to detect such a uniform mapping!

    𝜃1:hom𝒞︀(1,1)→Sub(1)𝜃1:id1=!1↦id1

    (On the left-hand side, id1:1→1 is a morphism; on the right-hand side, id1:1↪︎1 is a subobject in Sub(1).)

    Definition Representable functor [jc-000M]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a locally small category. A functor 𝐹:𝒞︀op→Set is called representable if there exist an object 𝑋 in 𝒞︀ and a natural isomorphism

    𝜃:hom𝒞︀(−,𝑋)≅𝐹

    In this case, 𝑋 is called the representing object of 𝐹. By the Yoneda lemma, 𝜃 is uniquely determined by an element 𝑒∈𝐹(𝑋), called the universal element of 𝐹. There is also a version for covariant set-valued functors 𝐺:𝒞︀→Set.

    Corollary Yoneda embedding [jc-000N]

    • November 3, 2026

    Let 𝒞︀ be a locally small category and 𝑋,𝑌 two objects of 𝒞︀. If we have an isomorphism

    hom𝒞︀(Γ,𝑋)≅hom𝒞︀(Γ,𝑌)

    natural in Γ (i.e. a natural isomorphism hom𝒞︀(−,𝑋)≅hom𝒞︀(−,𝑌)), then 𝑋≅𝑌. In the notation of generalized elements, it informally says that if 𝑋 and 𝑌 have the same generalized elements, then 𝑋 and 𝑌 are the same.
