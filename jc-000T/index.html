    Translating the greatest subobject [jc-000S]

    • November 3, 2026

    • As a natural transformation {∗}→hom(−,Ω), or as a universal element 1→Ω.
    • Prove that 𝑇↪︎Ω and 1↪︎Ω are the same subobject, getting back to the Wikipedia definition.

    In the previous section, we saw that the subobject classifier gives us the following data:

    • a universal subobject 𝑡:𝑇↪︎Ω (in fact, 𝑡=𝜒id𝑇:𝑇↪︎Ω);
    • for every subobject 𝑢∈Sub(𝐴), a unique morphism 𝜒𝑢:𝐴→Ω such that 𝑢∼𝜒𝑢−1(𝑡).

    In this section, we want to see how the subobject classifier internalizes some special subobjects as morphisms in the underlying category. Externally, we have the following concepts:

    • the equality of morphisms 𝑓=𝑔,
    • the membership 𝑥∈𝑢 of a generalized element in a subobject,
    • the logical “and”, or the intersection subobject 𝑢∩𝑣.
      We claim that we can convert each of these concepts into a morphism 𝑝:𝐴→Ω, and that we have a collection of specified morphisms true𝐴:𝐴→Ω, one for each 𝐴, such that 𝑝=true𝐴 is equivalent to 𝑓=𝑔, to 𝑥∈𝑢, or to 𝑞1=true𝐴∧𝑞2=true𝐴, respectively.

    First, we focus on finding out what true is.

    Recall the greatest subobject id𝐴:𝐴↪︎𝐴∈Sub(𝐴). We have seen that this construction is so uniform that the assignment

    {∗}→Sub{∗}→Sub(𝐴)∗↦id𝐴

    forms a natural transformation. Now, using the concept of representable functors: the constant singleton functor {∗} is represented by the terminal object 1, and the subobject functor Sub is represented by the subobject classifier Ω, so we have

    hom𝒞︀(−,1)≅{∗}→Sub≅hom𝒞︀(−,Ω)

    It sends !𝐴↦∗↦id𝐴↦𝜒id𝐴, and naturality says 𝜒id𝐵=𝜒id𝐴𝑓 for every morphism 𝑓:𝐵→𝐴. By the Yoneda lemma, computing id1↦∗↦id1↦𝜒id1, we get a universal element 𝜒id1:1→Ω such that 𝜒id𝐴=𝜒id1!𝐴 for every object 𝐴.

    If you didn’t shout “WOW” here, you should go back and do all three Key Exercises above.

    Spoiler warning!!!

    Both 𝑡 and 𝜒id1∈Sub(Ω) have the property that for every 𝑢∈Sub(𝐴) and every generalized element 𝑥:Γ→𝐴 of 𝐴, we have

    𝑥∈𝑢⇔𝜒𝑢𝑥∈𝑡𝑥∈𝑢⇔𝜒𝑢𝑥∈𝜒id1

    Both act like “true”! Indeed, taking 𝑢≔𝑡 in the second equation, we get 𝑥∈𝑡⇔𝜒𝑡𝑥∈𝜒id1; but 𝜒𝑡=idΩ by construction, so 𝑡∼𝜒id1∈Sub(Ω): they are indeed the same subobject!

    Proof of equation 1: by the property of 𝑡, we have 𝑢∼𝜒𝑢−1(𝑡). Expanding the definitions of ∼ and of preimages, we are done.
    Proof of equation 2: first, we have 𝑥∈𝑢⇔𝑥−1(𝑢)∼idΓ, since

    𝑥∈𝑢⇔𝑥idΓ∈𝑢⇔idΓ∈𝑥−1(𝑢)⇔idΓ≤𝑥−1(𝑢)⇔idΓ∼𝑥−1(𝑢)

    where we used that idΓ≤𝑥−1(𝑢) iff idΓ factors through 𝑥−1(𝑢), and that idΓ is the greatest subobject.
    Next, we show 𝑥−1(𝑢)∼idΓ⇔𝜒𝑢𝑥∈𝜒id1. If 𝑥−1(𝑢)∼idΓ, applying 𝜒 to both sides, we get

    𝜒𝑥−1(𝑢)=𝜒idΓ‖‖𝜒𝑢𝑥𝜒id1!Γ

    where the two vertical equalities use the naturality of 𝑢↦𝜒𝑢 and of !𝐴↦𝜒id𝐴. Therefore, 𝜒𝑢𝑥∈𝜒id1.
    Conversely, if 𝜒𝑢𝑥∈𝜒id1, say 𝜒𝑢𝑥=𝜒id1𝑦 for some 𝑦:Γ→1, then again by naturality, 𝜒𝑥−1(𝑢)=𝜒𝑢𝑥=𝜒id1𝑦=𝜒idΓ; therefore 𝑥−1(𝑢)∼idΓ.

    We should give the universal subobject a new name: true:1↪︎Ω, true≔𝜒id1; then true∼𝑡∈Sub(Ω). It can be understood as a global element of Ω, so it also corresponds to a collection of morphisms true𝐴:𝐴→Ω (in fact, true𝐴=𝜒id𝐴 and true1=true) which is invariant under context substitution: trueΓ𝜎=trueΔ for every 𝜎:Δ→Γ, and so

    true𝐴=true!𝐴

    for every object 𝐴.

    Finally, rewriting the results above, we have

    𝑥∈𝑢⇔𝜒𝑢𝑥=true!Γ

    for every subobject 𝑢∈Sub(𝐴) and generalized element 𝑥 of 𝐴. Equivalently, the following

    is a pullback square for every subobject 𝑢∈Sub(𝐴).

      Definition. monomorphism [jc-000X]

      • November 3, 2026
      • Justin

      A morphism 𝑚:𝐴→𝐵 in a category 𝒞︀ is a monomorphism (or is monic), written 𝑚:𝐴↪︎𝐵, if it can be cancelled on the left: for all morphisms 𝑥,𝑦:Γ→𝐴 with the same source,

      𝑚𝑥=𝑚𝑦⟹𝑥=𝑦.

      In the notation of generalized elements, postcomposition with 𝑚 never identifies two different generalized elements of 𝐴: for every context Γ, the function

      (𝑚∘−):hom𝒞︀(Γ,𝐴)→hom𝒞︀(Γ,𝐵)

      is injective. In Set, the monomorphisms are exactly the injective functions.
