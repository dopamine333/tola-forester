    Subobjects [jc-0007]

    • November 3, 2026
    • Justin

    To generalize subsets, we should look at monomorphisms 𝑖:𝑈↪︎𝐴. In the notation of generalized elements, the condition for 𝑖:𝑈↪︎𝐴 to be a monomorphism is: for all generalized elements 𝑥,𝑦 of 𝑈 with the same context, if 𝑖𝑥=𝑖𝑦 then 𝑥=𝑦 (notice that 𝑖𝑥 and 𝑖𝑦 are generalized elements of 𝐴). So postcomposition with 𝑖 can be seen as an inclusion of the generalized elements of 𝑈 into those of 𝐴.

    We can recover the notions of an element lying in a subset, of the inclusion relation between two subsets, and of when two subsets are considered equal.

    Definition [jc-0008]

    For a monomorphism 𝑢:𝑈↪︎𝐴 and a generalized element 𝑥:Γ→𝐴 of 𝐴, we write 𝑥∈𝑢 if 𝑥 factors through 𝑢, i.e., there exists a morphism 𝜑:Γ→𝑈 such that 𝑥=𝑢𝜑.

    Notice that such a 𝜑 is unique: if we have 𝜑,𝜓:Γ→𝑈 with 𝑥=𝑢𝜑 and 𝑥=𝑢𝜓, then 𝑢𝜑=𝑢𝜓 implies 𝜑=𝜓 by the monicity of 𝑢. So it is appropriate that the notation 𝑥∈𝑢 does not mention 𝜑.

    Definition [jc-0009]

    For monomorphisms 𝑢:𝑈↪︎𝐴 and 𝑣:𝑉↪︎𝐴, we write 𝑢≤𝑣 if for every generalized element 𝑥 of 𝐴, 𝑥∈𝑢 implies 𝑥∈𝑣. We write 𝑢∼𝑣 if 𝑢≤𝑣 and 𝑣≤𝑢.

    The following exercise shows that the definition of 𝑢≤𝑣 behaves as we expect and matches the definition on the nLab.

    Exercise [jc-000A]

    • November 3, 2026
    • Justin
    1. 𝑢≤𝑣 iff 𝑢 factors through 𝑣.
    2. The relation ≤ on monomorphisms into 𝐴 is a preorder.
    3. The relation ∼ is an equivalence relation on monomorphisms into 𝐴.
    4. 𝑥∈𝑢 and 𝑢≤𝑣 are well defined with respect to the equivalence relation ∼; that is, if 𝑢∼𝑢′ then 𝑥∈𝑢 iff 𝑥∈𝑢′, and if 𝑢∼𝑢′ and 𝑣∼𝑣′ then 𝑢≤𝑣 iff 𝑢′≤𝑣′.

    We close this section by giving the definition of the subobjects of an object 𝐴.

    Definition [jc-000B]

    • November 3, 2026
    • Justin

    The subobjects of 𝐴 are the equivalence classes of monomorphisms into 𝐴 under ∼; in notation, Sub(𝐴)≔{𝑢|𝑢:𝑈↪︎𝐴 monic}/∼. If the collection Sub(𝐴) is a set for every object 𝐴, the category is called well-powered.

      Definition. monomorphism [jc-000X]

      • November 3, 2026

      A morphism 𝑚:𝐴→𝐵 in a category 𝒞︀ is a monomorphism (or is monic), written 𝑚:𝐴↪︎𝐵, if it can be cancelled on the left: for all morphisms 𝑥,𝑦:Γ→𝐴 with the same source,

      𝑚𝑥=𝑚𝑦⟹𝑥=𝑦.

      In the notation of generalized elements, postcomposition with 𝑚 never identifies two different generalized elements of 𝐴: for every context Γ, the function

      (𝑚∘−):hom𝒞︀(Γ,𝐴)→hom𝒞︀(Γ,𝐵)

      is injective. In Set, the monomorphisms are exactly the injective functions.
