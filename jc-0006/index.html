    Generalized elements [jc-0004]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a category. In general, for an object 𝐴 in 𝒞︀, we can’t talk about an element of 𝐴. But from the categorical semantics of type theory, or through the lens of the Yoneda lemma, it seems to be a great idea to consider the generalized elements of 𝐴.

    Definition generalized element [jc-0005]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a category and 𝐴 an object of 𝒞︀. A generalized element of 𝐴 is a morphism into 𝐴

    𝑥:Γ→𝐴

    where Γ, the source of 𝑥, is called the context of 𝑥. In the case where 𝒞︀ has a terminal object 1 and the context of 𝑥 is 1, 𝑥 is called a global element of 𝐴.

    The notation of generalized elements makes reasoning about objects very much like reasoning about “sets”. The Yoneda embedding y:𝒞︀→Psh(𝒞︀),𝐴↦hom𝒞︀(−,𝐴) can be viewed as converting an object into its generalized elements, sorted by context (where Psh(𝒞︀)≔Set𝒞︀op is the presheaf category of 𝒞︀, and we should assume 𝒞︀ is locally small so that hom𝒞︀(−,𝐴) takes values in sets).     Exercise [jc-0006]

    • November 3, 2026
    • Justin

    Let 𝒞︀ be a category and 𝑓,𝑔:𝑋→𝑌 two morphisms in 𝒞︀. Show that 𝑓=𝑔 if and only if 𝑓𝑥=𝑔𝑥 for every generalized element 𝑥 of 𝑋 (where 𝑓𝑥 denotes the composite 𝑓∘𝑥).

    The name “global element” comes from the following understanding: if we have a global element 𝑐:1→𝐴, we can form the generalized element 𝑐!Γ:Γ→𝐴 for each object Γ, where !Γ:Γ→1 denotes the unique map into the terminal object. Such a collection of generalized elements {𝑐!Γ}Γ∈𝒞︀ is invariant under “context substitution”, in the sense that 𝑐!Γ𝜎=𝑐!Δ for every morphism 𝜎:Δ→Γ, since !Γ𝜎=!Δ. Conversely, if we have a collection of generalized elements {𝑐Γ:Γ→𝐴}Γ∈𝒞︀ invariant under context substitution, i.e. 𝑐Γ𝜎=𝑐Δ for every morphism 𝜎:Δ→Γ, then taking 𝑐1:1→𝐴, we have 𝑐1!Γ=𝑐Γ for each object Γ.
